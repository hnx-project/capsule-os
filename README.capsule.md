# 🐚 `userspace/posix/bash` — Vendored GNU Bash 5.3 for CapsuleOS

## What this directory is

A vendored copy of **GNU bash 5.3 stable** (released 2025-07-30), used as
CapsuleOS's userland shell. This is an **autotools-built POSIX userspace
program**, not a Cargo crate, and is built by an upcoming `xtask code bash`
subcommand rather than the regular `cargo` workspace.

The source here is byte-for-byte the upstream tarball
`https://ftp.gnu.org/gnu/bash/bash-5.3.tar.gz` (SHA-256 prefix
`0d5cd86965f869a26cf64f4b71be7b96f90a3ba8b3d74e27e8e9d9d5550f31ba`).

## Why vendor instead of git subtree

We initially planned `git subtree add ... https://git.savannah.gnu.org/git/bash.git`,
but the savannah mirror currently (2026-07) times out / is unreachable from
this build host. To unblock the Pangu 1.0.0.beta shell-compatibility work, we
vendored the official GNU FTP release tarball instead.

**Tradeoff**: we lose `git subtree pull` for incremental upstream sync. To
re-sync with a newer bash release, drop the vendored tree, download the new
tarball from `https://ftp.gnu.org/gnu/bash/`, re-extract, and re-apply any
capsule-local patches on top.

If/when the savannah mirror becomes reachable again, switching back to a
real `git subtree` is a one-shot:

```bash
git subtree add --prefix=userspace/posix/bash \
    https://git.savannah.gnu.org/git/bash.git bash-5.3
```

The three **capsule-specific** files in this directory are:

| File | Purpose |
|------|---------|
| `.gitignore` | Excludes autotools-generated outputs (Makefile, `bash`, `*.o`, `autom4te.cache`, ...) |
| `README.capsule.md` | This document |

## Cross-compilation flags (planned for next session)

```sh
./configure \
    --host=aarch64-unknown-capsule \
    --target=aarch64-unknown-capsule \
    --disable-nls \
    --without-bash-malloc \
    --disable-loadable-builtins \
    --enable-static-link \
    --with-included-gettext \
    --with-installed-readline=no \
    bash_cv_dev_fd=whence \
    CC=aarch64-unknown-capsule-gcc \
    AR=aarch64-unknown-capsule-ar \
    RANLIB=aarch64-unknown-capsule-ranlib
```

### Why each flag is needed

| Flag | Reason |
|------|--------|
| `--host=aarch64-unknown-capsule` | bash's autoconf `config.sub` may not recognise this triple yet; we expect a `support/config.sub` patch. |
| `--disable-nls` | bash uses GNU gettext; we don't ship it. Hard-disabling avoids locale-table lookups. |
| `--without-bash-malloc` | bash bundles its own `lib/malloc`; routing through libc malloc lets `libstd` (CapsuleOS Rust std) provide heap. |
| `--disable-loadable-builtins` | bash's dynamic-builtin loader uses `dlopen`/`dlsym` which aren't wired in 1.0. Static-only is fine for our usage. |
| `--enable-static-link` | All EL0 programs are statically linked today; mirrors the convention. |
| `--with-installed-readline=no` | bash can use the system readline or its own. We use bash's bundled readline (`lib/readline/`) so no extra cross-compile dep. |
| `bash_cv_dev_fd=whence` | bash's autoconf probes `/dev/fd/` to detect the kernel. CapsuleOS's fileagent doesn't expose it; we set the cache variable to "whence" so bash doesn't try `open("/dev/fd/N")` at startup. |

## Expected libc / libcapsule gaps

When `./configure` actually runs in a future session, we expect bash to call
into areas our current libc is thin on:

| Symbol | Source | Status in CapsuleOS 1.0 |
|--------|--------|-------------------------|
| `mmap` / `munmap` | bash uses these to seed large script file descriptors in some readline paths | **Not implemented** (W4 in Pangu 1.1) |
| `strsignal` | bash formats signal names from `strsignal(sig)` for `trap -p` | **Not exposed** in libcapsule |
| `wcwidth` | bash's prompt/PS1 needs column width for unicode | **Stubbed** in libcapsule |
| `nl_langinfo(CODESET)` | bash encodes LC_CTYPE output via nl_langinfo | **Stubbed** |
| `sigaction` with full flags | bash installs `SIGCHLD` handler with `SA_RESTART` | Minimal: only SIG_DFL/SIG_IGN today |
| `pipe2(O_CLOEXEC)` | bash creates pipes for `\|&` with close-on-exec | **Not implemented** |
| `dl_iterate_phdr` | dynamic loader probe | N/A (static link) |
| `waitid` (P_PID / P_PGID) | bash's job control calls this | **Not implemented** (1.1) |
| `grantpt` / `unlockpt` / `ptsname` | bash opens `/dev/ptmx` to allocate a pty | **Not implemented** (1.0 uses `tty` service) |

These will surface as missing-symbol errors when `./configure` and `make`
actually run. Each will be triaged one-by-one in subsequent sessions; some
will be fixed in libc/libcapsule (e.g. `wcwidth`), others worked around in
bash's `config.h` (e.g. `#define HAVE_MMAP 0`).

## Integration with xtask

The bash subtree will be picked up by a new `xtask.toml` schema entry:

```toml
[[subprojects]]
name = "bash"
type = "foreign"
src_path = "userspace/posix/bash"
configure = "./configure --host=aarch64-unknown-capsule ..."
build = "make -j$(nproc)"
artifact = "userspace/posix/bash/bash"
ohlink_entry = "65536"
staging_bin = "build/dist/staging_rootfs/system/bin/bash"
```

The new `build_foreign_subproject()` arm in `tools/xtask/src/build.rs`
will shell out to the configure + make pipeline and then run the existing
`cargo run -p ohlink-linker --` to OHLK-pack the resulting ELF into the
staging rootfs. **This change is not implemented in this commit** — the
skeleton is intentionally inert so we can iterate on the configure flags
without breaking the regular `cargo` build.

## Sync commands (future)

### Re-vendor from upstream FTP tarball

```sh
rm -rf userspace/posix/bash
mkdir -p userspace/posix
curl -L -o /tmp/bash.tar.gz https://ftp.gnu.org/gnu/bash/bash-X.Y.tar.gz
tar -xzf /tmp/bash.tar.gz -C userspace/posix
mv userspace/posix/bash-X.Y userspace/posix/bash
# restore the three capsule-local files from HEAD
git checkout HEAD -- userspace/posix/bash/.gitignore \
                       userspace/posix/bash/README.capsule.md \
                       userspace/posix/bash/capsule-configure.sh
```

### Switch to a true git subtree (once savannah is reachable)

```sh
rm -rf userspace/posix/bash
git subtree add --prefix=userspace/posix/bash \
    https://git.savannah.gnu.org/git/bash.git bash-X.Y
# re-apply the three capsule-local files
```
